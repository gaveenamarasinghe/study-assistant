# AI Study Assistant 📚🤖

An AI-powered Study Assistant Web Application designed to help students learn more effectively by generating study notes, summarizing educational content, and creating interactive quizzes based on a selected topic.

The application uses Artificial Intelligence to transform complex or lengthy study materials into easy-to-understand learning resources.

---

## 🚀 Features

### 📝 AI Note Generation
Enter a topic and generate structured, easy-to-understand study notes.

- Topic-based note generation
- Well-structured explanations
- Important concepts and key points
- Student-friendly content
- Organized headings and sections

### 📖 Note Summarization
Summarize lengthy study materials into concise and useful notes.

- Short and detailed summary options
- Extracts important information
- Removes unnecessary content
- Easy-to-read format
- Useful for quick revision

### 🧠 AI Quiz Generation
Generate quizzes automatically based on a selected topic or study material.

- Multiple-choice questions
- Automatically generated questions
- Multiple answer options
- Correct answer identification
- Quiz score calculation
- Instant feedback

### 🎯 Topic-Based Learning
Students can enter any supported academic topic and receive personalized learning content.
